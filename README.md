# N.O.V.A AI

A private, bilingual (Arabic/English) personal workspace built with Streamlit. N.O.V.A AI supports OpenAI-compatible providers, in-chat provider/model switching, guarded file access, user-reviewed file changes, public HTTPS reading, and manageable local memory and references. Local personalization retrieves relevant context; it does not train model weights.

> This is a single-user local application. Do not expose it to the public internet. Cloud AI providers receive the messages, file contents, and any local context you choose to use in a chat.

## Quick start

- **Windows:** run `launch_windows.bat`.
- **Linux/macOS:** run `bash launch_linux.sh`.
- Or install the requirements and run `streamlit run app.py`.

Choose **العربية** or **English** from the interface-language selector in the sidebar. See [the Arabic guide](README_AR.md) for setup, security notes, and current feature limits.
