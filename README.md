# Mas3edy Workspace

A local, Arabic-first personal AI workspace built with Streamlit. It supports OpenAI-compatible providers with in-chat provider/model switching, guarded file access, user-reviewed file changes, reading public HTTPS pages, and manageable local memory/knowledge/examples for contextual personalization. These features retrieve local context; they do not fine-tune model weights.

> This is a single-user local application. Do not expose it to the public internet. Cloud AI providers receive the messages, file contents, and any local context you choose to use in a chat.

## Quick start

- **Windows:** run `launch_windows.bat`.
- **Linux/macOS:** run `bash launch_linux.sh`.
- Or install the requirements and run `streamlit run app.py`.

See [التعليمات العربية](README_AR.md) for setup, security notes, and current feature limits.
