# مساعدي الشخصي — إصدار محلي

## التشغيل على Windows
1. ثبّت Python 3.11 أو أحدث.
2. فك ضغط المشروع.
3. شغّل `launch_windows.bat`.
4. افتح عنوان Streamlit المحلي الذي يظهر في الطرفية.
5. ادخل إلى الإعدادات وأضف مزودًا ومفتاح API وModel ID.

## مزودو النماذج
يتضمن إعدادات جاهزة لـ Groq وOpenAI وDeepSeek وOpenRouter، بالإضافة إلى عنوان مخصص متوافق مع OpenAI Chat Completions. توافق الأدوات يعتمد على المزود والموديل؛ بعض النماذج قد تدعم المحادثة دون استدعاء الأدوات.

## صلاحيات الملفات
- أضف كل مجلد تريد السماح بالوصول إليه يدويًا.
- يستطيع المساعد استعراض وقراءة الملفات النصية المحددة.
- الكتابة والنقل/إعادة التسمية تنشئ مقترحًا، ولا تنفذ إلا بعد موافقتك.
- تُرفض المسارات الخارجة عن المجلد المصرح به والملفات الحساسة والروابط الرمزية.
- لا يوجد حذف دائم أو تشغيل أوامر Shell أو تشغيل كود مولّد.

## الأمان والخصوصية
- لا تحفظ مفاتيح API في ملف الإعدادات. يحاول التطبيق استخدام نظام Keyring؛ وإذا لم يتوفر يحتفظ بالمفتاح في بيئة جلسة التشغيل فقط.
- المحادثات تحفظ محليًا في SQLite داخل مجلد بيانات المستخدم.
- عند استخدام مزود سحابي، تُرسل رسائلك وأي محتوى ملفات تختار قراءته إلى ذلك المزود. لا تستخدم ملفات سرية.
- قراءة الويب تقبل HTTPS فقط، وترفض التحويلات، وتتحقق من عناوين DNS قبل الطلب. هذا يقلل المخاطر لكنه ليس ضمانًا مطلقًا ضد DNS rebinding أو العمليات المحلية الخبيثة.
- التطبيق مخصص لمستخدم واحد وعلى جهاز موثوق. لا تعرضه على الشبكة العامة.

## الاختبارات
بعد تثبيت المتطلبات:
`python test.py`

الاختبارات محلية ولا تستدعي مزود AI أو الإنترنت.

## حدود الإصدار الأول
لا يتضمن Gmail، إرسال بريد، حذف ملفات، تشغيل برامج، أو تحكمًا ذاتيًا غير محدود بالجهاز. يمكن إضافة تكامل Gmail لاحقًا باستخدام OAuth وصلاحيات قراءة محددة بدل تخزين App Password.
