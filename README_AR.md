# N.O.V.A AI

مساحة عمل شخصية ثنائية اللغة (العربية والإنجليزية)، مبنية على Streamlit. غيّر لغة الواجهة من القائمة الجانبية. تدعم مزودي OpenAI-compatible، المحادثة، الملفات المصرح بها، مقترحات التعديل بعد الموافقة، قراءة صفحات HTTPS العامة، والذاكرة والمراجع المحلية.

## التشغيل

### Windows
1. ثبّت Python 3.11 أو أحدث.
2. شغّل `launch_windows.bat`.
3. افتح رابط Streamlit المحلي الذي يظهر في الطرفية.

### Linux أو macOS
1. ثبّت Python 3.11 أو أحدث.
2. من مجلد المشروع شغّل `bash launch_linux.sh`.
3. افتح رابط Streamlit المحلي الذي يظهر في الطرفية.

بعد التشغيل اختر **العربية** أو **English** من القائمة الجانبية. ثم افتح **الإعدادات** وأضف مزودًا، عنوان HTTPS، مفتاح API، وModel ID. عناوين HTTP غير مقبولة حتى لا يُرسل المفتاح عبر اتصال غير مشفر.

## ما يعمل حاليًا

- لوحة تحكم وإحصاءات محلية، وحفظ واستعادة المحادثات.
- محادثة عادية وبيئة برمجة محدودة بمجلدات تمنحها يدويًا.
- استعراض وقراءة ملفات نصية مسموح بها.
- مقترحات كتابة أو نقل ملفات: تظهر الرقعة للمراجعة، ولا تُنفذ إلا بزر **موافقة وتنفيذ**. يمكن رفضها، وتُرفض المقترحات إذا تغيّر الملف أو لم يعد المجلد مصرحًا به.
- قراءة صفحات HTTPS عامة دون اتباع التحويلات، مع فحص DNS وحد أقصى لحجم الاستجابة.
- سجل نشاط محلي، إدارة صلاحيات المجلدات والمزودين، وتبديل المزود والموديل مباشرة من المحادثة بعد تحديث قائمة الموديلات.
- ذاكرة وتفضيلات وتعليمات مخصصة، مع أمثلة يضيفها المستخدم يدويًا أو يحفظها من المحادثة.
- قاعدة معرفة نصية محلية قابلة للإضافة والحذف، واسترجاع بالكلمات المفتاحية مع معاينة ما سيُستخدم.

تظل أقسام الوكلاء والمشاريع والمهام والمستندات وسير العمل واجهات قيد التطوير. الذاكرة والاسترجاع والأمثلة تخصّص سياق المساعد فقط؛ لا تعيد تدريب أوزان الموديل.

## صلاحيات الملفات

- امنح التطبيق أقل عدد ممكن من المجلدات، ولا تمنحه مجلد المنزل أو جذر القرص إلا إذا كنت تقصد ذلك.
- تُرفض المسارات الخارجة عن المجلد المصرح به والروابط الرمزية والمسارات المعروفة لملفات الاعتماد، ومنها `.git` وملفات `.env` ومفاتيح SSH وملفات إعدادات الاعتماد الشائعة.
- قراءة الملفات محدودة إلى ملفات نصية صغيرة. إنشاء/تعديل الملفات محصور بالامتدادات النصية المدعومة، والنقل لا يحدث إلا بعد معاينة المقترح والموافقة الصريحة.
- توجد نسخ احتياطية قبل استبدال الملفات. لا يوجد حذف دائم أو تشغيل أوامر Shell أو تشغيل كود مولّد.
- لا تعتبر قائمة الحظر ضمانًا لاكتشاف كل سر ممكن؛ لا تمنح صلاحية لمجلدات تحتوي بيانات لا تريد إرسالها لمزود AI.

## الأمان والخصوصية

- لا تحفظ مفاتيح API في ملف الإعدادات. يحاول التطبيق حفظها في نظام Keyring؛ وإذا لم يتوفر، تبقى في بيئة عملية التطبيق حتى إغلاقها.
- المحادثات والملاحظات المحلية (الذاكرة، المعرفة، والأمثلة) تُحفظ في SQLite داخل مجلد بيانات المستخدم؛ تعليمات المساعد تُحفظ ضمن إعدادات التطبيق.
- عند استخدام مزود سحابي، تُرسل رسائلك ومحتوى الملفات التي تطلب قراءتها إلى ذلك المزود. وإذا فُعّل التخصيص، قد تُرسل أيضًا المقاطع المحلية التي يسترجعها السؤال. لا تحفظ أو تستخدم معلومات سرية.
- قراءة الويب تقبل HTTPS فقط، وترفض التحويلات، وتتحقق من عناوين DNS قبل الطلب. يظل هناك حدّ نظري لمخاطر DNS rebinding والبرامج المحلية الخبيثة.
- التطبيق مخصص لمستخدم واحد وعلى جهاز موثوق. لا تعرضه على الشبكة العامة.

## الاختبارات

بعد تثبيت المتطلبات شغّل الاختبارات من البيئة الافتراضية:

- Windows: `.venv\Scripts\python test.py`
- Linux/macOS: `.venv/bin/python test.py`

تغطي الاختبارات منع تجاوز المسارات والملفات الحساسة، التحقق من HTTPS، موافقات الملفات، وتغير الملفات قبل الموافقة، إضافةً إلى تخزين واسترجاع التخصيص المحلي. الاختبارات لا تستدعي مزود AI أو الإنترنت.

## حدود الإصدار الأول

لا يتضمن Gmail، إرسال بريد، حذف ملفات، تشغيل برامج، أو تحكمًا ذاتيًا غير محدود بالجهاز. كثير من أقسام التنقل ما زالت قيد التطوير.
